Colora

Accessible color picker web component for any framework, with OKLCH support and zero dependencies.

npm install @shinsekai/colora
GitHub

Highlights

  • Native popover

    Always on top. Clicks outside and Esc close it, and the focus goes back to where it was.

  • Your own input

    Link the picker to an existing text field with for. Typing and picking stay in sync.

  • Made for phones

    On small touch screens the popup becomes a bottom sheet with touch-sized controls.

  • Light on the page

    Popups only build their controls when first opened, so pages with many pickers stay fast.

  • Ready for forms

    Works like a native input: name, required, reset and disabled fieldsets.

  • Modern colors

    HEX, RGB, HSL, HSV, OKLCH and CMYK, plus all CSS named colors.

    With your own input

    Keep the text field of your form: it opens the picker, and typing and picking stay in sync.

    Click the field or press ↓ to open the picker, or type any CSS color.

    Code

    <form>
    <label for="brand">Brand color</label>
    <input id="brand" name="brand" value="#e91e63">
    <colora-picker
        for="brand"
        popup
        placement="bottom-start"
        formats="hex rgb oklch"
        swatches="#e91e63 #9c27b0 #3f51b5 #009688 #ff9800">
    </colora-picker>
</form>

    The input is submitted with the form, the picker has no name. Without JavaScript it's still a plain text field.
